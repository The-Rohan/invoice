Offline Urdu fish-market billing for Intel Mac and Windows x64.

## Downloads

- **Intel Mac:** download the `.dmg`, open it, and drag **Mandi Invoice** into Applications.
- **Windows:** download the `.exe` and run the setup wizard.
- `SHA256SUMS` contains checksums for both downloads.

Enter a customer, select/type each fish, enter its weight and negotiated rate, then save and print. Includes editable business details, invoice search, Urdu print preview and JSON backup/restore.

This preview is unsigned. macOS may require the per-app **Privacy & Security → Open Anyway** approval; Windows may show an unidentified-publisher warning. Do not disable OS protections globally.

Publication is gated on calculation tests and native source/packaged-app launch, save, PDF-generation and restart tests on Intel macOS and Windows. Automated checks do not cover the installer wizard, physical printers or every operating-system version.

This is a standalone app, not an Invoiso update; existing Invoiso data import is not implemented. Check the provisional Urdu wording and charges before using real bills.
